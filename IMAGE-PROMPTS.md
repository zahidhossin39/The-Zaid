# Service image prompts — "What I build" cards

Paste any prompt below into an image generator (Gemini app / "Nano Banana", ChatGPT, Midjourney).
Generate one image per service, keep the same **Option** across all three so the set matches.

**Card rules** (already baked into every prompt): landscape ~1.6:1, single subject filling ~60% of the frame,
wide empty margins, soft near-white background, one soft shadow, no text/logos. Export PNG.

The metaphors focus on the *business outcome*, so a non-technical owner gets it at a glance:
- **Apps** = the taped-together spreadsheet, rebuilt as a proper tool.
- **Automations** = the busywork runs itself while you step away.
- **Websites** = a machine that turns visitors into booked leads (not a brochure).
